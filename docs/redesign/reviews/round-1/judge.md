# Judge 1: blind comparison of Groschen screens

Main difference across the set: one version puts section navigation in a **top tab bar under the app header**, with a back-chevron eyebrow (for example "< VERMÖGEN") and a bottom nav spread across the full width. The other version puts **segmented controls or tabs under the page title**, uses a plain eyebrow, and its bottom nav items are bunched toward the left. Which letter carries the top-tab version changes from pair to pair: it is B in pairs 1-7 and A in pairs 9-10. Data content is the same in every pair.

## Pair 01: Ausgaben (phone, de)
| Rubric | Pick | Reason |
|---|---|---|
| Clarity of purpose | B | A stacks two segmented controls that both start with "Ausgaben" (Ausgaben/Einnahmen, then Ausgaben/Fixkosten). B makes Ausgaben/Fixkosten a top tab, so the two choices no longer look the same |
| Hierarchy | B | In B the section tab comes first, then the title, then the filter. In A two control rows of equal weight sit under the title |
| Task efficiency | B | In B you reach Fixkosten from a clear tab. In A you have to work out which "Ausgaben" pill does what |
| Data presentation | same | The sunburst, ranked list and year heatmap are identical |
| Navigation and naming | B | The top tab names the sibling page plainly. A repeats "Ausgaben" three times |
| Consistency | B | B uses the same top-tab pattern as the other B screens |
| Phone experience | B | B's bottom nav spreads across the full width. A's four items sit left with empty space on the right |
| Accessibility | B | Tabs are a recognisable pattern, and B avoids two identical labels in a row |
| Visual craft | B | B has less control clutter at the top and a balanced bottom bar |
**Overall: B.** A is not better anywhere important.

**Across pairs:** the top-tab version (B in pairs 1-7, A in pairs 9-10) works clearly better as a set:
- Each area (Spending/Fixed costs, Net worth/Depot, the Depot sub-pages) has one predictable tab bar above the title.
- Drill-downs get a "< parent" back link.
- On German phone screens no tab is clipped.
- The bottom nav is evenly spread.

The other version mixes segmented pills and tab rows that sit under the title. It repeats labels ("Ausgaben" twice), clips tabs on phone, and gives no way back except the bottom nav. The weak spot of the top-tab version is the ETF detail page, where two tab rows show the same "Analyse"/"Prognose" names. That page needs a different treatment, for example one tab row plus the back link. The other version's desktop drill-down eyebrow (pair 08 A) is slightly better.
